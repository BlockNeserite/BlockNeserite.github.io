# Through The Screen - 3D Eye Tracking

Приложение с отслеживанием глаз и 3D-моделями, создающее эффект глубины за экраном.

## Возможности

- **Отслеживание положения лица** через веб-камеру
- **Оценка расстояния** до экрана на основе размера лица
- **3D параллакс-эффект** - объекты кажутся находящимися за экраном
- **Режим реального времени** с плавной интерполяцией
- **Калибровка** для точной оценки расстояния

## Технологии

- **Three.js** - рендеринг 3D-графики
- **face-api.js** - распознавание лиц и лендмарков
- **WebRTC** - доступ к камере

## Запуск на компьютере

1. Откройте `index.html` через локальный веб-сервер:

```bash
# Используя Python
python -m http.server 8000

# Или используя Node.js (http-server)
npx http-server
```

2. Откройте браузер: `http://localhost:8000`

3. Разрешите доступ к камере

4. Нажмите "Запустить отслеживание"

## Запуск на телефоне

Просто открыть `index.html` из файлового менеджера недостаточно: браузеры iPhone и Android блокируют камеру на страницах `file://`. Нужна HTTPS-ссылка.

Самый простой вариант — загрузить всю папку проекта на GitHub Pages, Netlify или другой статический хостинг с HTTPS. Загружать нужно не только `index.html` и `app.js`, но также папки `vendor` и `models`. После публикации откройте HTTPS-ссылку на телефоне и разрешите доступ к камере.

Для проверки в одной Wi-Fi сети можно запустить сервер на компьютере:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте на телефоне `http://АДРЕС_КОМПЬЮТЕРА:8000`. В большинстве мобильных браузеров камера по обычному HTTP не разрешается, поэтому для реального использования предпочтителен HTTPS-хостинг. `localhost` на телефоне означает сам телефон, а не компьютер.

Модели распознавания и JavaScript-библиотеки теперь находятся внутри проекта, поэтому после первой публикации приложение не зависит от CDN и не должно зависать на сообщении «Загрузка моделей распознавания лиц».

## Использование

1. **Запуск**: Нажмите кнопку "Запустить отслеживание"
2. **Калибровка**: Отойдите на 60 см от экрана и нажмите "Калибровка"
3. **Перемещение**: Двигайте голову влево-вправо, вверх-вниз, приближайтесь/отдаляйтесь
4. **Наблюдайте**: 3D-объекты будут реагировать на ваше положение

## Как это работает

- Камера определяет положение вашего лица (X, Y)
- По ширине лица оценивается расстояние (Z)
- Камера Three.js перемещается в противоположном направлении
- Создается иллюзия, что объекты находятся за экраном

## Примечания

- Требуется HTTPS или localhost для доступа к камере
- На телефоне `file://` не подходит — используйте HTTPS
- Лучше работает при хорошем освещении
- Оптимальное расстояние: 40-80 см от экрана
